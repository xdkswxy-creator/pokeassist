# 对战助手（PokeMMO 随机 PvP）

一个跑在你自己电脑上的小网页，用来在打随机 PvP 的时候告诉你：**这一回合出哪招胜率最高**。
电脑和手机都能用（手机连同一个 WiFi 就能打开），不需要联网下载东西、不需要花钱的 API。

---

## 一、怎么启动

1. 双击文件夹里的 **`启动助手.bat`**。
2. 会跳出一个黑窗口（**别关它**，它就是服务器），同时浏览器会自动打开 `http://127.0.0.1:8765/`。
3. 黑窗口里会打印两行地址：
   - 电脑上用：`http://127.0.0.1:8765/`
   - 手机上用：`http://192.168.x.x:8765/`（同一个 WiFi 下）
4. 关闭时：直接关掉那个黑窗口。

> 如果双击后被 Windows 提示风险，点"更多信息 → 仍要运行"。它只是个本地小服务器，不联网。

## 二、怎么用

### 第 1 步：准备（每把对战开始前花 1～2 分钟）

- 页面最上面是 **数据池**：你录入过的精灵都会自动记在这里，**点一下就能把整只（含 4 个招式、道具、特性）填进空位**。第一把录入过之后，后面遇到同一只精灵就不用再点了——选精灵时会自动填好。
- 上半部分 **我方队伍**：点第一个 "+ 选择精灵"，输入精灵名搜索（中文名如"烈咬陆鲨"，英文名也行），选好后进去把 **4 个招式**填上，道具/特性/性格能填就填（不填也不影响出招建议）。
- 下半部分 **对手队伍**：把你在游戏里能看到的对手 4 只选上，**能看到的招式填进去**。填得越全，建议越准。

### 导入自己整理的数据

右上角菜单 → **数据（精灵配招库）**：

- 可以粘贴 CSV（Excel 里排好另存为 CSV）或 JSON，一列一只精灵：
  ```
  精灵,招式1,招式2,招式3,招式4,道具,特性,性格
  烈咬陆鲨,地震,逆鳞,尖石攻击,剑舞,生命宝珠,沙隐,爽朗
  ```
- 也可以"从文件读取"，或者把库里已有数据"导出"发给朋友。
- 库存在服务端（`data/shared.json`），**同一个网址的所有人共用一份**，别人录入的你也立刻能用。

### 第 2 步：对战

1. 点"开始对战"。
2. 中间 **推荐** 区域会列出这一回合所有可选动作和估计胜率，排第一的就是建议你做的。
   - 卡片上会写"对 耿鬼 100-100%、命中 100%、可击杀 62%、先手/后手"。
   - 点右上角"查看全部"能看到所有选项。
3. 下面一行 **对手出招**：选对手这回合最可能出的招（默认"自动（最坏）"，即按对手最有利的一招来算，最保守）。
4. 游戏里做完动作后，点 **结算回合**，助手会模拟这一回合并更新胜率。
   - 如果游戏里实际结果和模拟不一样（比如暴击、miss、血量对不上），点 **修正血量/状态** 手动改。
5. 点错了就点 **撤销上回合**。

顶部会一直显示当前是第几回合。

## 三、它算的"胜率"是什么

- 它会把你这回合的每个动作 × 对手可能的每个动作都模拟一遍，看打完之后双方还剩多少血、还剩几只，折算成 0~100% 的胜率估计。
- **命中率**：威力 80% 命中的招式会让胜率按"打中 80% / 打空 20%"加权，不会再被当成必中。
- **暴击**：击杀概率会把第五世代 1/16 的暴击率算进去（暴击伤害翻倍，常常能把"打不死"变成"斩杀"）。
- 这个数字**不是精确的**，它主要用来比较"哪个动作比哪个好"，绝对数值别太当真。
- 对手没填的招式：如果池子里有这只精灵的固定配招，就按池子来；没有才按"最可能带的招"猜。
- 计入了：属性克制、本系加成（STAB）、天气、能力等级变化、命中率、优先度、先手/后手、道具（命玉/专爱/剩饭等）、特性（威吓/浮游/技术高手等）、替身/状态/寄生种子/沙暴冰雹/反射壁光墙、击杀后下一只上场。

## 四、数据和规则范围

- 只包含**第五世代（黑白2）及以前**的精灵、招式、特性、道具 —— 因为 PokeMMO 只到第五世代。
- 精灵 698 只、招式 572 个、特性 164 个、道具 540 个，全部有中文名。
- 等级默认 **Lv.75**（随机对战常见等级）。数据来源：宝可梦对战模拟器 Pokémon Showdown 的公开数据 + PokeAPI 的中文名。
- 按第五世代规则算：暴击 2 倍、灼伤每回合掉 1/8、钢属性抗恶/鬼。

## 五、已知的不足

- 不会算太复杂的连锁（比如"接棒+强化"的组合收益），主要是单回合前瞻 + 一回合推演。
- 双打/三打招式、变化招式的特殊效果只实现了一部分（比如灭亡歌、临别礼物没算）。
- 对手的道具、特性如果没填，就按"没有"算（会略微高估你的伤害）。

## 六、遇到问题

- **手机上打不开**：①手机和电脑要连同一个 WiFi；②第一次启动时 Windows 可能会弹"防火墙"提示，要点**允许访问**；③网址里的 `192.168.x.x` 每次换 WiFi 可能会变，以黑窗口里显示的为准。
- **黑窗口一闪就没了**：说明没找到 Python，按窗口里的提示截图发我。
- **提示端口被占用**：脚本会自动往后找端口，黑窗口里显示哪个就用哪个。
- **想先随便看看效果**：在浏览器地址后面加 `?demo=1`，或者点右上角菜单里的"载入示例对战"。

## 七、以后想更新数据

数据在 `data/gen5/` 里，是 JSON 文件。更新方式是重新跑 `tools/` 里的脚本（需要 Python），普通使用不需要碰它。

## 七、文件都在哪

```
pokeassist/
├─ 启动助手.bat        ← 双击这个启动
├─ server.py           ← 本地服务器（自动开浏览器、显示手机地址）
├─ web/                ← 网页本体（index.html / css / js）
│  └─ js/engine/       ← 对战模拟引擎（伤害计算、回合推演、胜率评估）
└─ data/gen5/          ← 精灵/招式/特性/道具数据（第五世代）
```

## 想让朋友也能用？（不用租服务器、不用付钱）

双击 **启动并分享.bat**，等十几秒，窗口里会出现一个网址，比如：
`https://xxxx.lhr.life`（已经自动复制到剪贴板）

把这个网址发给朋友就行，**手机、电脑都能打开**，大家用的是同一份数据。

要注意的三件事：

1. **你这台电脑和这个窗口不能关**，关了别人就打不开；
2. **网址每次启动都会变**，重开之后发新网址；
3. 免费通道偶尔会断，断了就关掉窗口重新双击一次。

> 什么时候才需要真的租服务器？只有当你想要"网址固定不变、电脑关了别人也能用"的时候。
> 那时按 `deploy.md` 做，一个月大概 5~10 元。

## 最快的录入方式：截图识别（不用一个个搜）

1. 游戏里按 **Win + Shift + S**，框选精灵卡（**名字和 4 个招式都要在里面**）；
2. 回到助手的队伍页，点 **📷 识图**；
3. 在弹出的框里按 **Ctrl + V** 粘贴（手机就点「选择图片」从相册选）；
4. 等两秒，自动认出「精灵 / 招式 / 道具 / 特性」，确认后点 **全部填到对方**（或我方）。

用的 Windows 自带文字识别：**不联网、不花钱、不用装东西**。
字认得不准时会按最接近的名字去猜，猜不准的会标红让你手动改。

## 对战页怎么操作（3 个按钮）

- **选招**：中间「推荐」里点任意一张卡片 = 这回合让这只用这招（点「查看全部」能看到所有可选，包括换人和轮转）。
- **对手出招**：对手那一行右边的 **「对手出招 ▾」**，或最下面的 **「② 对手出招」**。
  他出了你没录过的招式？弹窗里点 **「＋ 直接选一个招式」**，搜名字选上，助手会**自动记进他的配招**，下次直接在列表里。
- **结算回合**：最下面 **「③ 结算回合」**。点错了就「↶ 撤销上回合」。

第一次进对战页会有 3 条引导，点「知道了，不再显示」可以关掉；想再看一次：右上角 ☰ → 重看操作引导。

### 填错了怎么办

- **删一招**：点精灵卡 → 招式右边 **✕**。
- **删一整只**：☰ → 数据（精灵配招库）→ 那一行右边 **✕**。删完会同步给朋友，不会又冒出来。
- **防手滑**：选的招式如果是这只精灵一般学不会（比如给九尾填「破壳」），会先弹框让你确认；
  实在需要（随机对战偶尔有奇怪配招）点「确实是这样，加上」就好。
- 已经录进库里的错误招式，编辑里会标一个「可能填错」的小红标，方便你找出来删。

---

## 血量不准 / 属性相克

- **血量**：点精灵卡 →「✎ 修正」→ 最上面的 **满血值** 填游戏里的真实最大血量（个体值随机，算不出来的就手填），再拖百分比。填过会记住。
- **属性相克**：已按第五世代修正（17 个属性，没有妖精系；钢系仍抗恶、抗鬼）。推荐卡上会显示「克制×2 / ×4」。

## 悬浮窗（不用切浏览器）

双击 **`悬浮窗.bat`**（要先开着服务）。会弹出一个 400×620 的小窗口，固定在最前面，
里面就是精简版的对战页：推荐出招、对手出招、结算，都在里面点。

## 对手那边

- 每只精灵卡片上都写了 **道具**（对手没填的会写「道具未知」）。
- 对手倒下后要换第 4 只出来时，会**自动弹窗问「对手换上了哪只？」**，从你库里点一下就好。
  没弹也可以点对手那行右边的 **「＋新精灵」**。
- 记录对手招式时，会先列出 **「这只可能还有这些招（池子里见过的）」**，点一下就记上。

## 数值口径

- 池子里的精灵：**个体值全满（31）、努力值每项 85**、性格按中性算。
- 满血值可以在「✎ 修正」里手填（个体值随机，算不出来的就填真实值）。
- 和后台第 4 只交换会清掉能力变化；场上 3 只之间轮转**不清**。白色香草会自动清掉下降。

## 三个提速技巧

1. **任意位置 Ctrl+V 就能识图**，不用先点开「识图」。
2. **键盘 1 / 2 / 3** 选第 1/2/3 个推荐，**回车** = 结算回合（电脑上很快）。
3. 开着**悬浮窗**，游戏和助手并排，不用来回切。

## 对手道具（推测）

对手道具看不到，助手会按你库里**同一只精灵以前带过的道具**推测，
卡片上显示「推测：生命宝珠」，并且**参与伤害计算**（白色香草、专爱、吃剩的东西都会算）。
库里没这只的记录时显示「道具未知」，就按没道具算。
