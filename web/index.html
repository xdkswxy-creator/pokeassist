最快的录入方式：截图识别

游戏里按 Win + Shift + S 框选精灵卡（名字和 4 个招式都要在里面），回到队伍页点 📷 识图，按 Ctrl + V 粘贴。两秒后自动认出精灵、招式、道具、特性，确认一下点 「全部填到对方 / 我方」就行。手机上点「选择图片」从相册选也可以。
识别用的是 Windows 自带的文字识别（不联网、不花钱）；认错的字会按最接近的名字去猜， 猜不准的会标出来让你手动改。

怎么用

  1. 队伍页：把游戏里看到的 4 只我方精灵点进去（精灵、4 个招式、道具、特性）。对手的精灵也填上，招式不知道就留着。
  2. 对战页：助手每回合给出前 3 个推荐和胜率估计。点一张卡就是你这回合要做的操作。
  3. 游戏里对手真正出完招后，点 结算回合。助手会按你选的"对手出招"（默认取对你不利的一招）推进一回合。
  4. 如果和游戏里实际的伤害不一样（暴击、miss、随机浮动），点 修正血量/状态 把真实数字填回去，下一回合的推荐会更准。

对战页的三个按钮在哪

对战页从上到下是：对手场上的精灵（这一行右边有「对手出招 ▾」按钮）→ 推荐出招（点卡片就是选它） → 我方场上的精灵 → 最下面一排是「② 对手出招」和「③ 结算回合」。

要填对手这回合用了什么：点对手那一行右边的「对手出招 ▾」，或最下面那个「② 对手出招」，是一样的弹窗。
他用了你没录过的招？弹窗里点「＋ 直接选一个招式」，直接搜招名选上——助手会自动把这一招记进他的配招里， 下一回合就不用再填了。

填错了怎么改 / 删

点精灵卡打开编辑：每个招式右边有个 ✕，点一下就删掉这一招；点招式本身可以换成别的。
整只录错了：☰ → 数据（精灵配招库），每只右边也有 ✕，删掉后朋友那边也会同步删掉。
如果选的招式这只精灵一般学不会（多半是点错了），会让你确认一次，选「不加」就行。

三个提速技巧

①任意位置 Ctrl+V 就能识图，不用先点「识图」；②键盘 1 / 2 / 3 选推荐、回车 结算； ③用悬浮窗，游戏和助手并排（先开「启动助手.bat」，再双击「悬浮窗.bat」）。

对手的道具看不到：助手会按你库里同一只以前带过的道具推测（卡片上写「推测：X」），也算进伤害。

数值是按这个池子的规则算的

个体值全满、努力值每项 85、性格按中性。满血值可以手填（个体值随机，算不出来就填真实值）。
能力变化：和后台第 4 只交换会清掉；场上 3 只之间轮转不清。白色香草会自动清掉下降。

血量不准怎么办

点精灵卡 →「✎ 修正」里最上面有 满血值，填游戏里这只的最大血量（比如纽拉 206）， 再拖动百分比条。填过一次之后会记住，下次同一只精灵直接用。

“轮转”是怎么算的

你场上的 3 只都能在任意回合直接接手上场并当回合出招，不消耗额外回合；对手的攻击会打在你轮转上场的那只身上。所以每回合的推荐本质是「3 只 × 各自的招式」里挑最优，外加「换上第 4 只」这个不吃伤害但也不输出的选项。

它是怎么判断“最优”的

  • 用第五世代的伤害公式模拟每个候选操作；
  • 对你可能的每个操作 × 对手可能的每个操作（已知招式 + 未知时按最强招估算 + 换人）全部推演一遍；
  • 按最坏情况为主（65%）+ 平均情况（35%）打分，再对前几名多推演一回合；
  • 分数换算成 0–100% 的胜率估计——这是相对参考，不是绝对概率。

小技巧

  • 优先看胜率最高的那张卡，但也要看它下面写的「对谁多少伤害」——有时第二张更稳。
  • 对手的招式每暴露一个就补进去，推荐会明显变准。
  • 血量填得越准，判断越准。别嫌麻烦，点一下「修正」就行。
